NAYI PICTURE LAGANA (2 tareeqe)
1) Browser mein: address ke aakhir mein #edit likhein (index.html#edit).
   Har card par "Upload picture", "Rename", "Delete" aate hain. Neeche "Add card" se naya card.
   Ye picture sirf usi browser mein save hoti hai.
2) Website par sab ko dikhane ke liye: picture ko images/ folder mein 01.jpg, 02.jpg ... naam se rakhein
   (card number ke mutabiq, .png/.webp bhi chalta hai), phir poora folder hosting par upload karein.
